## Why Setting Location is Important

- Location is a prerequisite for creating a TC Target Area  
- Without location data, further mapping and planning cannot proceed

## Methods to Set Location

You can set a Paul’s location using either of the following methods:

1. **Using Longitude and Latitude**
   - Preferred method for accuracy  
   - Ensures precise mapping  

2. **Using Village Name**
   - Alternative method when coordinates are not available  
   - Less precise but acceptable  

---

## Video Showing How to Set a Location for a Paul


### 1. Using Latitude & Longitude Data

![[]]

#### Steps

1. Select the Paul  
2. Navigate to the location field  
3. Enter the latitude and longitude coordinates  
4. Verify the location on the map  
5. Save the changes  

---

### 2. Using Village Name

![[WithLocRecording 2026-02-19 122523-20260219124433-3yt4d2r.mp4]]

#### Steps

1. Select the Paul  
2. Navigate to the location field  
3. Search for the village name  
4. Select the correct village from the suggestions  
5. Verify the mapped location  
6. Save the changes
