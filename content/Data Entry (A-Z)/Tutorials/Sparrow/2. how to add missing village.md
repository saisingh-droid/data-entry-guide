# Process Flow

```mermaid
flowchart TD

%% Nodes
A[Missing Village Identified]
B[Connect with Mapping Specialist]
C{Additional Checks / Validation}
D[Enter Village in Sparrow]
E[Review by India ACHIEVE-Tech]
F{Approved?}
G[Publish Update]
H[Survey Entry for Village]
I[Reprint Updated TCTA]

%% Annotations using comment shapes
MS@{ shape: brace-l, label: "👤 Done by Mapping Specialist" }
NOTE@{ shape: brace-l, label: "📝 Maintain missing village data separately - Excel / Forms" }

%% Flow
A --> B
B --> C
C -->|Valid| D
D --> E
E --> F
F -->|No| B
F -->|Yes| G
G --> H
H --> I

%% Annotation Links
H -.-> MS
I -.-> MS
D -.-> NOTE

%% Invisible Layout Helpers
NOTE ~~~ E
MS ~~~ I

%% Styling
classDef start fill:#2563eb,color:#ffffff,stroke:#1e3a8a,stroke-width:2px;
classDef process fill:#7c3aed,color:#ffffff,stroke:#4c1d95,stroke-width:2px;
classDef validation fill:#facc15,color:#000000,stroke:#ca8a04,stroke-width:2px;
classDef review fill:#fb923c,color:#000000,stroke:#c2410c,stroke-width:2px;
classDef success fill:#16a34a,color:#ffffff,stroke:#14532d,stroke-width:2px;

%% Apply Classes
class A start;
class B process;
class C validation;
class D process;
class E review;
class F validation;
class G success;
class H success;
class I success;

%% Loop Highlight
linkStyle 2 stroke:#ef4444,stroke-width:2px;
linkStyle 5 stroke:#ef4444,stroke-width:2px;
```
